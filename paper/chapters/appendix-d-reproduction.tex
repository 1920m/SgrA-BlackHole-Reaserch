\chapter{The Reproduction Pipeline}
\label{app:repro}

The top-level \texttt{Makefile} exposes the automation targets.
\texttt{make figures} regenerates every figure in this report from the
current artefacts with Matplotlib (data plots from
\texttt{scripts/make\_figures.py}, schematics from
\texttt{scripts/make\_diagrams.py}). \texttt{make thesis} runs
\texttt{figures} and compiles this document
(\texttt{pdflatex}$\times3$ + \texttt{bibtex}); \texttt{make paper} does
the same for the companion journal paper. \texttt{make reproduce}
re-runs the science chain end-to-end in gate order:
\begin{enumerate}
\item \texttt{ctest} --- the full physics and science unit-test suite
(every gate-0 tolerance of Chapter~\ref{ch:devhistory});
\item \texttt{render\_reference} --- Schwarzschild and Kerr reference
renders with 32-direction boundary metrology (JSON);
\item \texttt{subring\_tool} --- disk render, beaming asymmetry, sub-ring
isolation and flux ratios;
\item \texttt{fit\_s2\_tool} in \texttt{kerr} and \texttt{nohair} modes ---
the fits of Chapters~\ref{ch:fitting} and \ref{ch:nohair};
\item \texttt{sweep\_tool} --- the \sgra{} calibration point and the
$20\times20$ $(\astar,i)$ sweep;
\item \texttt{make\_figures.py} --- figure regeneration from the
artefacts.
\end{enumerate}
\texttt{scripts/make\_numbers.py} then rewrites \texttt{numbers.tex}, the
macro file from which every simulation-derived number in this text is
typeset. A stale or hand-edited number cannot survive a
\texttt{make reproduce} cycle.

For this report, \texttt{make reproduce} runs the following additional
steps after the journal-paper chain above, before regenerating figures
and numbers:
\begin{enumerate}
\setcounter{enumi}{6}
\item \texttt{physics\_tables} — Kerr radii, energetics, efficiency and
Novikov--Thorne profiles over the spin grid (Chapters~\ref{ch:kerr},
\ref{ch:disk});
\item \texttt{convergence\_tool} — the projection/drift/step-size
studies (Chapter~\ref{ch:numerics});
\item \texttt{sweep\_tool photonorbits} — the spherical-orbit and
Lyapunov families (Chapter~\ref{ch:shadow});
\item \texttt{subring\_tool --sweep} — sub-ring flux ratios and widths
over spin (Chapter~\ref{ch:ring});
\item \texttt{handedness\_tool} — the image-handedness measurements of
Appendix~\ref{app:handedness}: both camera conventions on the same
integrator, the mirror identity, and the Kerr--Schild cross-check;
\item \texttt{run\_mcmc.py both} — the Kerr and no-hair ensemble
posteriors via the \texttt{fit\_s2\_tool --chi2} server
(Chapters~\ref{ch:fitting}, \ref{ch:nohair});
\item \texttt{fit\_cluster} — the joint five-star mass fit
(Chapter~\ref{ch:cluster});
\item \texttt{make\_diagrams.py} — the explanatory schematics of
Part~I.
\end{enumerate}
The single command \texttt{make thesis} runs \texttt{figures} and
compiles this document; the fetch of the multi-star data
(\texttt{fetch\_gillessen\_data.py}) is a one-time network step run
before the cluster fit.

\section*{Environment}
\addcontentsline{toc}{section}{Environment}

The chain assumes: a C++20 toolchain with the vcpkg manifest
dependencies (Eigen, Ceres, Catch2, spdlog, nlohmann-json; Vulkan SDK
components only for the engine targets), CMake presets
\texttt{core-rel}/\texttt{sci-rel}/\texttt{engine-rel}, Python~3.11
with \texttt{numpy}, \texttt{matplotlib}, \texttt{emcee} and
\texttt{pypdf}, and a \LaTeX{} distribution with \texttt{natbib}
(TinyTeX suffices). No step requires a GPU except the engine renders
and the CPU/GPU comparison; every scientific number in this report is
reproducible on a CPU-only machine.

\section*{Verifying this document}
\addcontentsline{toc}{section}{Verifying this document}

The document itself is checked by a text-level probe after each full
build: the compiled PDF is read back with \texttt{pypdf} and scanned
for (i) unresolved references (the doubled question mark \LaTeX{}
prints for a missing label — spelt out here so the probe does not
catch its own description), (ii) raw macro
names (a backslash followed by a macro identifier surviving into the
output, which would indicate a missing \texttt{numbers.tex}
definition), (iii) the presence of every headline number, and (iv) the
policy that the contested star S62 must carry its caveat at every
mention. The probe, the zero-error requirement on the
\LaTeX{} log, and the page-count band of the plan together define
``compiles clean'' wherever this report uses the phrase.
