\chapter{Number Provenance}
\label{app:provenance}

Every simulation-derived number in this report is a \LaTeX{} macro
generated by \texttt{scripts/make\_numbers.py} from a machine-readable
artefact, regenerated end-to-end by \texttt{make reproduce}
(tests $\to$ reference renders $\to$ sub-ring metrology $\to$ S2 fits
$\to$ calibration and sweep $\to$ figures). Table~\ref{tab:prov} maps the
headline numbers to their artefacts; the verification-gate table with the
measured results lives in Chapter~\ref{ch:devhistory}
(Table~\ref{tab:gates}).

Tables~\ref{tab:macros1} and \ref{tab:macros2} go one level deeper:
they list \emph{every} macro of \texttt{numbers.tex} with its current
value and source artefact. The values printed here are typeset from
the macros themselves, so this appendix can never disagree with the
body text — if \texttt{make reproduce} changes a number, it changes
here too.
